# Retail Sales Dashboard

Interactive retail sales dashboard developed as part of
the VEDA Technology Data Analytics Internship – Task 3.

## Objective

To create an interactive dashboard showing sales performance
using cleaned retail sales data.

## Tools

- Power BI
- Microsoft Excel
- Python / Pandas (for previous data cleaning)

## Dashboard Features

- Total Sales
- Total Units Sold
- Total Transactions
- Average Transaction Value
- Sales by Item
- Monthly Sales Trend
- Sales by Location
- Payment Method filter

## Interactivity

The dashboard includes slicers that allow users to filter
the sales data dynamically.

## Dataset

The dashboard uses the cleaned retail sales dataset prepared
during the previous data-cleaning task.
